# ROSALIOU Design Pilot

Use the approved scope, screen inventory, and architecture as input. Create original user experiences rather than reproducing protected third-party brand assets or proprietary interface content.

1. Specify responsive layouts, navigation, empty, loading, error, and success states for each screen.
2. Establish reusable design tokens, typography, components, and accessible contrast.
3. Describe keyboard navigation, focus management, screen reader labels, and localization including RTL where required.
4. Define validation and permission-denied states and tenant-safe data presentation.
5. Produce component acceptance criteria and a sandbox-only test checklist.
6. Present designs for review before implementing production changes.

Do not scrape, copy protected designs, use private endpoints, deploy to production, or modify payment and messaging integrations.
